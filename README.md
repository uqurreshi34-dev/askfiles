# AskFiles — AI File Manager
![CI](https://github.com/uqurreshi34-dev/askfiles/actions/workflows/ci.yml/badge.svg)
AI-powered Android file manager - file management made easy

## Live
[Google Play Store](https://play.google.com/store/apps/details?id=com.askfiles.mobile)
[Landing Page](https://uqurreshi34-dev.github.io/askfiles/)

## Stack
- React Native / Expo SDK 54
- Native Kotlin modules (file ops, media grid, storage stats, tags, favourites)
- Django REST Framework backend
- Groq LLM (AI search)
- RevenueCat (in-app purchases)

## Features
- Native file browser with copy, move, rename, zip, extract
- Password-protected ZIP and 7z extraction with AES-256 encryption
- Document scanner powered by Google ML Kit
- SMB, SFTP and FTP file management
- WebDAV support (Nextcloud compatible)
- Wi-Fi file transfer
- QR file transfer and file share
- Tags — colour-coded file organisation across folders, synced via cloud backup (Pro)
- Smart search — search inside documents (Pro)
- AI-powered file search (Pro)
- Secure vault with PIN + biometric lock
- Google Drive, OneDrive & Dropbox backup with settings sync (Pro)
- Duplicate file finder (Pro)
- Recycle bin with 30-day restore
- PDF tools — create, merge, extract pages
- OCR text extraction from images
- Video summary with ML scene detection
- Android home screen widget
- Dark mode
- App lock with PIN + biometrics
